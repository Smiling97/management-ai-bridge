# Management AI Bridge

Management AI Bridge is an open knowledge hub for translating GenAI capabilities into responsible, practical management work.

The project serves management scholars, educators, students, and practitioners who want to use AI for research, teaching, organizational analysis, decision support, and productivity without treating AI as only a technical engineering topic.

## What This Repository Contains

- A GitHub Pages website in `docs/`
- AOM workshop archive pages for 2025 and 2026
- Applied tutorials for management workflows
- A prompt library organized by task
- Curated courses, tools, papers, and communities
- Responsible AI guidance for academic and organizational use
- GitHub issue templates for community contributions

## Publishing With GitHub Pages

1. Create a public GitHub repository.
2. Push this folder to the repository.
3. Open repository settings.
4. Under **Pages**, choose **Deploy from a branch**.
5. Select the main branch and the `/docs` folder.
6. Save the settings and wait for GitHub Pages to publish the site.

## Contributing

Community members can contribute by opening GitHub Issues using the templates in `.github/ISSUE_TEMPLATE/`.

Good contributions include:

- Management-focused prompts
- Short tutorials
- AOM workshop links and summaries
- Course and tool recommendations
- Corrections to outdated or inaccurate content

See [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines.
