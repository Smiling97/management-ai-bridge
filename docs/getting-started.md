# Getting Started

Use this site as a working library, not as a course to read from beginning to end.

## Choose a Task

Start with the management task you need to complete:

- Review literature.
- Develop theory or compare constructs.
- Prepare teaching materials.
- Analyze an organizational situation.
- Draft a decision memo.
- Improve a productivity workflow.

## Use the Workflow Pattern

For any GenAI-assisted task, use the same review cycle:

1. Define the management task.
2. Provide context, audience, constraints, and source material.
3. Ask for a structured output.
4. Review accuracy, assumptions, missing evidence, bias, privacy, and usefulness.
5. Revise the prompt or output.
6. Document how AI was used when needed.
