# Research Prompts

## Literature Synthesis Matrix

### Use Case

Organize verified source notes into a management literature synthesis.

### Input Needed

Research question, source notes, abstracts, and target construct.

### Prompt

```text
Use only the source notes I provide. Create a literature synthesis matrix for this management research question: [question].

Source notes:
[paste notes]

Columns: source, construct, theory, method, finding, boundary condition, relevance, verification needed.
Then summarize three tensions across the literature.
```

### Expected Output

A structured matrix plus concise synthesis of tensions.

### Review Criteria

Check every claim against the original sources and remove unsupported synthesis.

## Construct Clarification

### Use Case

Clarify similarities and differences among related management constructs.

### Input Needed

Construct names, definitions, and source excerpts.

### Prompt

```text
Compare these management constructs using only the definitions and excerpts provided.

Constructs: [list]
Definitions and excerpts:
[paste material]

Create a comparison with: core meaning, overlap, differences, level of analysis, common measures, and risks of construct confusion.
```

### Expected Output

A construct comparison that helps refine theory or measures.

### Review Criteria

Confirm that distinctions are grounded in the supplied definitions.

## Theory Development Critique

### Use Case

Stress-test an emerging theoretical argument.

### Input Needed

Draft argument, assumptions, context, and outcome of interest.

### Prompt

```text
Critique this management theory argument.

Argument:
[paste argument]

Identify: core causal logic, hidden assumptions, alternative explanations, boundary conditions, missing mechanisms, and testable propositions.
Use a constructive scholarly tone.
```

### Expected Output

A structured critique that improves clarity and testability.

### Review Criteria

Preserve the author's intended contribution while challenging weak logic.
