# Teaching Prompts

## Class Session Plan

### Use Case

Design a management class around specific learning objectives.

### Input Needed

Course level, topic, objectives, readings, class length, and student background.

### Prompt

```text
Create a management class session plan.

Course level: [level]
Topic: [topic]
Learning objectives: [objectives]
Class length: [minutes]
Readings/case facts: [notes]

Include: opening question, mini lecture, discussion sequence, activity, debrief, closing synthesis, and likely misconceptions.
```

### Expected Output

A usable teaching plan with discussion flow and instructor notes.

### Review Criteria

Check alignment with learning objectives and adjust for classroom context.

## Case Discussion Questions

### Use Case

Prepare questions for a management case discussion.

### Input Needed

Case summary, learning goal, and target student level.

### Prompt

```text
Create discussion questions for this management case.

Case summary:
[paste summary]

Learning goal: [goal]
Student level: [level]

Produce: opening question, diagnostic questions, debate questions, decision questions, and closing reflection.
```

### Expected Output

A sequenced set of discussion questions.

### Review Criteria

Questions should invite analysis rather than one correct answer.

## Assignment Rubric Draft

### Use Case

Create a first-draft rubric for management assignments.

### Input Needed

Assignment instructions, learning objectives, and grading priorities.

### Prompt

```text
Draft a rubric for this management assignment.

Assignment:
[paste instructions]

Learning objectives: [objectives]
Grading priorities: [priorities]

Create criteria, performance levels, point values, and feedback language. Flag any ambiguity in the assignment instructions.
```

### Expected Output

A rubric draft with criteria and feedback language.

### Review Criteria

Verify fairness, clarity, and fit with course expectations.
