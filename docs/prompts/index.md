# Prompt Library

The prompt library is organized by management task. Each prompt includes a use case, input needed, reusable prompt, expected output, and review criteria.

- [Productivity Prompts]({{ '/prompts/productivity-prompts/' | relative_url }})

## Prompt Use Principles

- Provide context, audience, constraints, and source material.
- Ask for uncertainty, assumptions, and missing information.
- Treat outputs as drafts to review, not answers to trust.
- Do not submit confidential, private, or sensitive material without approval.
