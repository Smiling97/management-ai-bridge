# Courses

## Recommended Starting Points

### Generative AI Basics

Use beginner GenAI courses to understand large language models, prompting, multimodal models, risks, and responsible use.

### Prompt Engineering

Prioritize courses that teach task framing, context design, iteration, evaluation, and limitations rather than only lists of prompt formulas.

### AI for Research Workflows

Look for courses that cover literature review, data analysis, coding assistance, synthesis, and research transparency.

### AI for Teaching and Learning

Prioritize resources that address assignment design, feedback, academic integrity, accessibility, and student learning outcomes.

## Submission Notes

When submitting a course, include:

- Course title
- Provider
- Link
- Cost
- Skill level
- Why it is useful for management users
- Any limitations or caveats
