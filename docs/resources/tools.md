# Tools

This page organizes tool categories rather than endorsing one default tool.

## Tool Categories

### General GenAI Assistants

Useful for brainstorming, drafting, summarizing, planning, and critique when paired with careful review.

### Literature and Research Tools

Useful for search, citation mapping, paper summarization, and research organization. Verify all claims against original sources.

### Writing and Editing Tools

Useful for clarity, structure, tone, and feedback. Preserve the author's judgment and voice.

### Data and Coding Assistants

Useful for code explanation, statistical workflow support, data cleaning plans, and reproducible analysis checks.

### Teaching Tools

Useful for case preparation, quiz drafts, rubric drafts, and classroom activity design.

## Review Questions

- What data does the tool store?
- Can confidential or student data be entered?
- Does the tool cite sources reliably?
- Can outputs be exported or documented?
- What human review is required before use?
