# GenAI for Teaching Preparation

## Purpose

Use GenAI to prepare management teaching materials that are clear, relevant, inclusive, and aligned with learning goals.

## When To Use

Use this workflow when designing a class session, discussion plan, case prompt, assignment, rubric, or feedback guide.

## Workflow

1. Define the course level, session topic, learning objectives, and student background.
2. Provide readings, case facts, or lecture notes.
3. Ask for multiple teaching options instead of one final answer.
4. Select and revise the option that best fits your classroom.
5. Check for hidden assumptions, unsupported claims, and inaccessible examples.
6. Adapt language to your teaching voice.

## Example Prompt

```text
I am preparing a management class session.

Course level: [undergraduate/MBA/PhD/executive]
Topic: [insert topic]
Learning objectives:
[insert objectives]
Readings or case facts:
[paste notes]

Create a 75-minute session plan with:
1. Opening question
2. Short framing lecture
3. Discussion sequence
4. Small-group activity
5. Debrief questions
6. Closing synthesis
7. Likely student misconceptions
8. Instructor notes for handling disagreement
```

## Output Review Checklist

- Does the plan directly support the learning objectives?
- Are discussion questions open enough to create useful debate?
- Are examples appropriate for the student population?
- Are sensitive topics handled with care?
- Is the instructor still making the pedagogical judgment?

## Risks

AI-generated teaching materials can be bland, inaccurate, culturally narrow, or misaligned with course goals. Review all content before use and avoid uploading confidential student work.
