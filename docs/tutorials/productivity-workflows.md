# GenAI for Productivity Workflows

## Purpose

Use GenAI to reduce friction in recurring management knowledge work while preserving quality, accountability, and confidentiality.

## When To Use

Use this workflow for drafting agendas, summarizing notes, preparing follow-up emails, creating checklists, refining arguments, or turning rough notes into structured plans.

## Workflow

1. Identify a recurring work pattern.
2. Define the desired output format.
3. Provide nonconfidential context and constraints.
4. Ask the AI system to produce a structured draft.
5. Edit for accuracy, tone, audience, and omissions.
6. Save prompts that consistently improve the workflow.

## Example Prompt

```text
Convert these rough notes into a management work product.

Audience: [insert audience]
Output type: [agenda/memo/checklist/email/action plan]
Tone: [concise/formal/collaborative]
Constraints: [length, deadline, sensitive topics]
Notes:
[paste notes]

Produce:
1. A clean version of the output
2. A list of missing information
3. Any risks or assumptions
4. A shorter version if appropriate
```

## Output Review Checklist

- Is the output accurate and complete?
- Does it match the intended audience?
- Are action items specific and owned?
- Is confidential information protected?
- Is the final text still in the user's voice?

## Risks

Productivity gains can create overreliance, privacy exposure, and generic communication. Keep human review in the workflow and avoid entering sensitive data into systems that are not approved for that use.
