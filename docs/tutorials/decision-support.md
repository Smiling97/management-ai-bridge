# GenAI for Decision Support

## Purpose

Use GenAI to improve the structure of management decisions by clarifying options, assumptions, evidence, tradeoffs, and risks.

## When To Use

Use this workflow when preparing a strategic recommendation, policy decision, resource allocation, project prioritization, or leadership memo.

## Workflow

1. Define the decision and decision owner.
2. List options, constraints, criteria, and available evidence.
3. Ask for a decision matrix and assumptions audit.
4. Identify what evidence would change the recommendation.
5. Ask for downside risks and implementation requirements.
6. Rewrite the final recommendation in your own judgment.

## Example Prompt

```text
Help structure a management decision. Do not make unsupported claims.

Decision: [insert decision]
Options: [list options]
Criteria: [list criteria]
Evidence: [paste known evidence]
Constraints: [budget/time/political/ethical constraints]

Create:
1. A decision matrix
2. Key assumptions behind each option
3. Risks and second-order effects
4. Evidence gaps
5. A recommendation only if the evidence supports one
6. A short executive memo draft
```

## Output Review Checklist

- Are criteria explicit and relevant?
- Are assumptions visible?
- Are evidence gaps acknowledged?
- Does the recommendation follow from the analysis?
- Are ethical and stakeholder consequences considered?

## Risks

AI systems can make premature recommendations, hide value judgments, or present uncertain tradeoffs as precise calculations. Use the output as scaffolding for human decision-making.
