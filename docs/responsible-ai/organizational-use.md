# Responsible Organizational Use

## Core Practices

- Protect confidential, personal, customer, employee, and strategic information.
- Check whether the tool is approved by the organization.
- Keep humans accountable for consequential decisions.
- Document how AI contributed to analysis or recommendations when appropriate.
- Consider stakeholder effects, fairness, and unintended consequences.

## Decision Support

AI can help compare options, identify assumptions, draft memos, and run pre-mortems. Managers should review evidence, values, tradeoffs, and implementation risks directly.

## Organizational Learning

Teams should treat AI use as a learning practice. Useful routines include shared prompt libraries, review checklists, approved-use guidelines, and periodic reflection on what AI improves or weakens.
